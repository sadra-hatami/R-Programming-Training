# 📖 About

**Introduction to R Programming** is an educational repository with five interactive Jupyter notebooks that teach the core building blocks of R.

The lessons start from the simplest ideas — numbers, characters, variables, and logicals — then move to vectors, lists, matrices, and data frames, continue with importing and inspecting data, add conditionals and loops, and finish with writing reusable functions.

Each notebook includes short explanations, runnable examples, and practice exercises so you can learn by doing, not only by reading.

> **Tagline:** *A practical R learning repository covering data types, data structures, importing data, control flow, and functions through interactive Jupyter Notebooks.*

# 📚 Lessons

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [Lesson_1_R_Basic_Data_Types.ipynb](Lesson_1_R_Basic_Data_Types.ipynb) | Numbers (integer / numeric), characters, `print()`, variables, `cat()`, logicals, comparison and logical operators |
| 2 | [Lesson_2_R_Data_Structures.ipynb](Lesson_2_R_Data_Structures.ipynb) | Vectors, lists, matrices, data frames, subsetting, naming, missing values (`NA`) |
| 3 | [Lesson_3_Importing_Data.ipynb](Lesson_3_Importing_Data.ipynb) | `read.csv()`, `read.table()`, `head()`, `tail()`, `unique()`, `table()` |
| 4 | [Lesson_4_Conditionals_and_Loops.ipynb](Lesson_4_Conditionals_and_Loops.ipynb) | `if`, `else if`, `else`, `for` loops, `seq_along()` |
| 5 | [Lesson_5_Functions.ipynb](Lesson_5_Functions.ipynb) | Defining functions, parameters, `return()`, `sapply()`, `apply()`, `help()` / `?` |

### Suggested order

1. Start with **Lesson 1** to understand values and variables.
2. Continue with **Lesson 2** to store and organize data.
3. Use **Lesson 3** to bring external data into R.
4. Practice decisions and repetition in **Lesson 4**.
5. Finish with **Lesson 5** to wrap logic inside functions.

# 🧠 What You Will Learn

- Integer and numeric values, and basic arithmetic
- Character strings, `paste()`, and printing output
- Variable names, assignment with `<-`, and formatted printing with `cat()`
- Logical values (`TRUE` / `FALSE`) and comparisons
- Vectors, lists, matrices, and data frames
- Importing CSV and table files
- Inspecting data with `head()`, `tail()`, `unique()`, and `table()`
- Conditional statements and `for` loops
- Writing functions that take input and return results
- Applying functions with `sapply()` and `apply()`

# ▶️ How to Use

### Option 1 — Open on GitHub

1. Open this repository.
2. Click any `.ipynb` file.
3. Read the cells and review the examples.

### Option 2 — Run locally

```bash
git clone https://github.com/sadra-hatami/Introduction-R-Programming.git
cd Introduction-R-Programming
```

Then install Jupyter if needed:

```bash
pip install notebook
jupyter notebook
```

If you prefer the classic R environment, you can also open the same ideas in RStudio after installing R.

Open the lesson files one by one and run the cells.

### Option 3 — Google Colab

Upload any notebook to [Google Colab](https://colab.research.google.com/) and run it in the browser with no local setup.
